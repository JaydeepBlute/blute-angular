GPS feed is integrated from the operator's fleet management system (external REST, polled every 60 s). WebSocket pushes location to Angular web and Flutter mobile clients. Graceful degradation: "Location unavailable" shown if GPS feed is down. Counter flow uses the same booking saga APIs as the passenger portal but tags each booking with channel=COUNTER, counter_id, and shift_id. Cash refunds on cancellations appear as negatives in the shift reconciliation report. Commission accrues on base fare only — levies are excluded. A nightly batch job evaluates agents.cumulative_bookings and auto-upgrades tiers. Once earned, a tier is never revoked (annual fraud review only). Chartered bookings follow a 5-stage lifecycle: REQUEST → QUOTED → APPROVED → ADVANCE_PAID → COMPLETED. Each stage triggers SMS + email notifications to the booking contact.
